## Learned User Preferences

- Keep the server a small local MCP wrapper around Google's official Search Console API for Cursor. Shipped tools are `list_sites`, `search_analytics`, `inspect_url`, `list_sitemaps`, `add_site`, `remove_site`, `submit_sitemap`, and `remove_sitemap`.
- The scope is `https://www.googleapis.com/auth/webmasters`. A stored `https://www.googleapis.com/auth/webmasters.readonly` token returns `not_logged_in` until `node dist/main.js login` runs again. URL removal from Google Search is absent. The Indexing API stays out.

## Learned Workspace Facts

- TypeScript MCP server named `gsc` with stdio and streamable HTTP entries. Commands are `node dist/main.js login`, `node dist/main.js serve`, and `GSC_HTTP_PORT=<port> node dist/main.js serve-http`. Cursor starts the stdio server from `.cursor/mcp.json`. Dependencies are `@modelcontextprotocol/server`, `@modelcontextprotocol/node` for the HTTP mount, `google-auth-library` for OAuth, and Zod. `Catalog` in `src/console.ts` is the only tool-name list, and `src/main.ts` registers its keys. `SEARCH_TYPES`, `GROUP_DIMENSIONS`, `AGGREGATION_TYPES`, `DATA_STATES`, `OPERATORS`, and `DEVICE_NAMES` are the only copies of those sets.
- `GSC_OAUTH_CLIENT_FILE` is a Desktop OAuth client JSON outside the repo. `GSC_OAUTH_WEB_CLIENT_FILE` is Google's unmodified Web-application client JSON download, and `GSC_LOGIN_REDIRECT_URL` is the byte-exact registered browser login redirect; both are set only for `serve-http`. The token file defaults to `~/.local/share/gsc-mcp/token.json` (`GSC_TOKEN_FILE` overrides), mode `0600`, and stores the refresh token, `https://www.googleapis.com/auth/webmasters`, and `client` (`web` or `desktop`, the kind that minted it; absent loads as `desktop`). Each kind mints with its own client file. The process reads the file at startup and caches the access token in memory; a 401 refreshes once. A browser login through `GET /login/` and `/login/callback` publishes the file and adopts the token into the running `serve-http` process without a restart. Login leaves stdout empty. A missing token still lets Cursor list tools; calls then return `not_logged_in`. A stored read-only scope also returns `not_logged_in` and does not call Search Console. After a workstation CLI `login`, restart the server.
- mini.local serves the HTTP build: `/srv/gsc-mcp` holds rsynced `dist`, `node_modules`, and `package.json`. systemd `gsc-mcp.service` (unit kept in `deploy/gsc-mcp.service`) runs `serve-http` as `toni` on `127.0.0.1:8097`, and nginx `location ^~ /mcp/gsc` in `/etc/nginx/sites-enabled/llmstudio` publishes `https://mini.local/mcp/gsc/`. `client.json`, `client-web.json`, and `token.json` live in `toni`'s home on mini with mode `0600`; after a workstation `login`, copy `token.json` over and restart the service, or open `https://mini.local/mcp/gsc/login/` and the service adopts the token itself. `serve-http` answers `403` outside the `mini.local` and loopback `Host`/`Origin` allowlist, for the login routes too. Without `GSC_OAUTH_WEB_CLIENT_FILE` and `GSC_LOGIN_REDIRECT_URL` the login routes answer `503` and every `not_logged_in` keeps the CLI text.
- Failures are `invalid_args`, `not_logged_in`, `not_in_property`, `google_http`, and `bad_response`. Messages name the next action and omit tokens, client secrets, and raw response bodies.
- `search_analytics` dates are inclusive `YYYY-MM-DD` in Pacific Time and are passed through unchanged. Filters are `device`, `country`, `page`, `query`, and `searchAppearance`. `date` and `hour` only group rows. Grouping by `hour` requires `dataState` `hourly_all`. Pages default to 25 rows and stop at 100. The wire `rowLimit` is one higher, and `nextStartRow` is set only when that extra row returns. Row `dimensions` are keyed by the requested dimension names.
- `inspect_url` reports the indexed URL. Referring URLs, sitemaps, AMP issues, and rich-result items stay in Google's order, capped at 20, with separate full counts. `list_sitemaps` lists sitemaps. `add_site` adds a property and `remove_site` deletes one. `submit_sitemap` submits a sitemap and `remove_sitemap` deletes one. `permissionLevel` stays an open string. A URL-prefix property ends with a slash. A domain property looks like `sc-domain:example.com`.
- `origin` is a bare repository on `mini.local`. `gh` is not installed here, so GitHub pull requests are not opened from this checkout. `main` and `origin/main` contain the Search Console MCP server.
